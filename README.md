## How I work

- **Set the limits first.** Every tool call has a defined scope, every trace has an owner, and every retry knows what already happened.
- **Make claims you can check.** Tests cover the failure paths, examples run, and each README says plainly what the code doesn't do.
- **Remember the user.** Reliability matters because someone is trying to get work done.
